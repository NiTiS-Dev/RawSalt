# RawSalt Engine

## Requirements

### Operating system support

| Platform |    Requirements    |
|:--------:|:------------------:|
|  Win32   |    Windows 10+     |
|   Xlib   | Not supported yet. |
| Wayland  | Not supported yet. |
| Android  | Not supported yet. |

|   API   |    Requirements    |
|:-------:|:------------------:|
| Vulkan  |        1.3+        |
| DirectX | Not supported yet. |
|  Metal  | Not supported yet. |
| OpenGL  |    Not planned.    |
